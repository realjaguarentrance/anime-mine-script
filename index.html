Features

Six core modules working together so you can set a route once and let the script handle the grind.

Continuously cycles your configured mining path, re-targeting nodes as they break. No idle frames, no manual clicks.

✨

ESP Ore Highlights

See valuable ores through walls with color-coded highlights and distance tags, so you never walk past a vein again.

Teleport-to-Node

How it works

Set up in three steps.

From download to first auto-mine run in under two minutes.

1

Download & unpack

Grab the latest build for Windows from the download page, extract it to any folder, and launch the executable. No installer, no dependencies.

2

Pick a mining profile

Choose a route preset or edit your own node list, then bind your toggles in the config panel. Hotkeys default to F6 for the overlay and F7 for auto-mine.

3

Run the loop

Hit start and the script handles mining, ore highlighting, node teleports, and auto-sell cycles while you monitor the live stats overlay.
